One spoken sentence

1
The shopper opens the React web app, hosted on AWS Amplify, in a browser on a computer or phone, and signs in. Amazon Cognito authenticates them and returns JWT tokens; its identity pool exchanges them for temporary AWS credentials that allow one action only: opening the session host WebSocket.
2
The browser opens a SigV4-signed WebSocket to the session host on Amazon Bedrock AgentCore Runtime, one microVM per shopping session. The first message carries the Cognito token, which the host verifies before anything else. Mic audio then streams in 64 ms frames, or the shopper types.
3
Amazon Nova 2.5 Sonic on Amazon Bedrock is a speech-to-speech model. It listens to the stream and returns text transcripts of what the shopper said: partial transcripts start a speculative catalog search, and the final one starts the turn. It then speaks the reply the app gives it, out loud only when Voice is on or to ask a yes/no question.
4
The turn pipeline asks Strands Decider 2B on an Amazon SageMaker AI real-time endpoint typed questions in parallel: intent, who it is for, department, category, which card, and change-of-mind re-checks. Each answer returns with a calibrated probability, and per-question thresholds decide: act, show results and ask one question, or treat it as not said. Exact numbers such as budgets are parsed in code.
5
Tool calls go over MCP, with IAM authentication, through Amazon Bedrock AgentCore Gateway to five AWS Lambda functions. AgentCore Memory keeps the shopper's preferences for the next visit.
6
The search_catalog Lambda function runs in an isolated VPC subnet. It embeds the shopper's query with Amazon Titan Text Embeddings V2 and runs a filtered vector search in Amazon OpenSearch Serverless, both through VPC endpoints. The product detail, cart and order tools use Amazon DynamoDB; cart and order writes are idempotent transactions.
7
Chips and the shelf update first, in about a second. Product images load from a private Amazon S3 bucket through presigned URLs valid for one hour. An order always needs a separate yes, and no payment is taken.

Deploy and operations

D
deploy-all.sh deploys the stacks with the AWS CDK. AWS CodeBuild builds both container images (no local Docker) into Amazon ECR, copies the pinned model weights to Amazon S3, and loads the generated catalog into Amazon S3, Amazon DynamoDB and the search index.
O
Amazon CloudWatch keeps logs, per-turn records and latency metrics. AWS IAM gives each component its own least-privilege role.
