One spoken sentence

1
The shopper opens the React web app on AWS Amplify.
2
Amazon Cognito signs the shopper in and returns JWT tokens; its identity pool gives credentials that can only open the WebSocket.
3
The browser opens a SigV4-signed WebSocket to the session host on Amazon Bedrock AgentCore Runtime and streams mic audio or text.
4
Amazon Nova 2.5 Sonic, a speech-to-speech model on Amazon Bedrock, returns transcripts and speaks the app's reply.
5
The session host asks Strands Decider 2B on Amazon SageMaker AI typed questions; per-question thresholds on the calibrated answers decide to act, ask one question, or ignore.
6
Tools run over MCP through Amazon Bedrock AgentCore Gateway on five AWS Lambda functions; AgentCore Memory keeps preferences.
7
The search_catalog function, in an isolated VPC subnet, embeds the query with Amazon Titan Text Embeddings V2 (7a) and searches Amazon OpenSearch Serverless (7b) through VPC endpoints.
8
Product detail, cart and order tools use Amazon DynamoDB; the session host saves its own state there directly.
9
Chips (preference labels) and the shelf update in about a second; images load from a private Amazon S3 bucket through presigned URLs.

Deploy and operations

D
deploy-all.sh deploys with the AWS CDK; AWS CodeBuild builds the images into Amazon ECR and loads the catalog.
O
Amazon CloudWatch keeps logs and metrics; AWS IAM gives each component a least-privilege role.
