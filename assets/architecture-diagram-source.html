One spoken sentence

1
The shopper signs in with Cognito; the Identity Pool gives the browser temporary credentials for one thing only: the session host WebSocket.
2
The browser opens a SigV4-signed WebSocket to the session host on AgentCore Runtime and streams mic audio (or typed text).
3
Nova 2.5 Sonic transcribes; it speaks only with Voice on, or to ask a yes/no question. Partial transcripts start a speculative catalog search; the final one starts the turn.
4
The host asks Strands Decider typed questions: intent, who it is for, department, then category within it, budget, which card. Each answer has a calibrated confidence: act, ask one question, or offer a yes/no.
5
Tools run through AgentCore Gateway to five Lambda functions. Code enforces every committed filter. Memory keeps preferences for the next visit.
6
search_catalog runs in a VPC: it embeds the query with Titan and runs a filtered vector search in OpenSearch Serverless through the collection's VPC endpoint. The cart and orders are DynamoDB transactions.
7
Chips and the shelf update first (about 1 s); product images arrive as presigned S3 URLs.

Deploy time

D
deploy-all.sh builds the images in CodeBuild (no local Docker), creates the endpoint, and loads the generated catalog from the repository zip; a function inside the VPC writes the search index.
